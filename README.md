# Main Memory Atelier

A standalone React + Vite interactive learning website for Main Memory.

## Includes
- Interactive 3D RAM and ROM module
- RAM: SRAM and DRAM
- ROM: PROM, EPROM and EEPROM
- RAM vs ROM comparison
- Storage → RAM → CPU animation-style learning flow
- Beginner school analogy
- Power ON/OFF concept
- Quick quiz
- Responsive UI

## Run

```bash
npm install
npm run dev
```

Then open the local Vite URL shown in the terminal.

## Build

```bash
npm run build
```

## Deploy to Vercel

Import this folder's GitHub repository into Vercel. Vercel should detect Vite automatically.

Build command:
`npm run build`

Output directory:
`dist`
